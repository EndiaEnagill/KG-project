# GitHub 项目考古学家 · 数据工作台

双击 `启动工具.cmd` 打开桌面界面。输入GitHub仓库链接即可进行API采集；默认勾选在API结束后补采本地Git。

已经有数据时，使用“打开已有结果”选择任务目录，再点击“为当前结果补采本地 Git”，不需要重新爬取Issue、PR和评论。

- [本地Git采集使用说明](本地Git采集使用说明.md)：操作、保存位置、输出文件、关系定义、补查和限制。
- [项目文件说明与数据处理流程](项目文件说明与数据处理流程.md)：原API采集及处理流程。
- [全量采集说明](全量采集说明.md)：API全量范围。

程序使用Python标准库和Tkinter；本地Git功能额外需要Git for Windows。`git_collect.py`负责Git缓存及非覆盖式补采，`test_git_collect.py`验证真实本地Git历史、重命名、二进制差异、合并提交、重复补采与取消。

本工具输出可供知识图谱构建的结构化数据，不直接启动图数据库。历史函数映射、语义抽取和首次发布推断尚未实现。
